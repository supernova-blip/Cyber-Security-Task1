# Cyber Security Task 1 – Vulnerability Assessment Report

## Overview

This repository contains the deliverables for Cyber Security Task 1 assigned by Future Interns.

The objective of this task was to perform a passive vulnerability assessment of a public web application and document the findings in a professional security report.

## Target Application

IBM Altoro Mutual Demo Banking Application

Target URL:
https://demo.testfire.net

## Assessment Scope

The assessment was conducted using a read-only and ethical approach.

Included:

* Public-facing pages
* Header analysis
* Cookie inspection
* Network exposure analysis
* Passive vulnerability scanning

Excluded:

* Exploitation
* Brute force attacks
* Authentication bypass
* Denial-of-Service testing

## Tools Used

* Browser DevTools
* Nmap
* OWASP ZAP

## Findings Summary

The assessment identified multiple security observations, including:

* Missing Security Headers
* Server Information Disclosure
* Missing SameSite Cookie Attribute
* Additional Service Exposure
* Potential SQL Injection Indicators
* Potential Reflected Cross-Site Scripting (XSS) Indicators
